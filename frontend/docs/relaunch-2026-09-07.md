## Root cause and fix

The SVG itself matched staging. Production lacked staging's early bootstrap that changes only Balam's
requested closed shadow root to open, hides the host until branded, and installs the custom launcher.
The React effect could not reach a closed shadow root. Prior DOM fixtures assumed an accessible root;
HTTP 200 for the image could not establish actual branding. Both gaps are now covered.

The staging bootstrap is loaded before hydration/provider startup using root-layout `beforeInteractive`.
It is idempotent and does not change other elements' closed shadow roots. See Next.js 14's documented
script ordering: https://nextjs.org/docs/14/app/api-reference/components/script#beforeinteractive.
The existing custom SVG/branding is retained. The prior React observer replacement fix is also retained.
